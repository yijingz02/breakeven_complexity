# Breakeven Complexity

Code base for paper "Breakeven complexity: A new perspective on neural partial differential equation solvers".

Training codes inherited from original [FFNO](https://github.com/alasdairtran/fourierflow), [EddyFormer](https://github.com/ASK-Berkeley/EddyFormer), [Poseidon](https://github.com/camlab-ethz/poseidon), [DPOT](https://github.com/HaoZhongkai/DPOT), [DISCO](https://github.com/RudyMorel/DISCO), and [Walrus](https://github.com/PolymathicAI/walrus) repo.
